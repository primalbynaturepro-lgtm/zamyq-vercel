This folder is the deployable copy of the ZAMYQ & cowcottes seller page — one static
`index.html`, the thing that goes on the web when Amandine's site is published.

It is the page's destination, not where it is drawn. The drawing, its catalogue and its review
bench live in `PxN/redline/showcase/zamyq/site/`, and that is where changes are made and
walked. This folder receives the result.
